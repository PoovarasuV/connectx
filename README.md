# ConnectX

ConnectX is a social activity and intent-based connection platform.

Instead of simply following people or consuming content, users can post
what they want to do and discover people who want to do the same thing.

## Core Product Loop

Intent → Matching → Join → Community → Activity → Reputation

## Vision

Build a platform that helps people find the right people,
activities, communities, and experiences around them.
